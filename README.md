# 📱 Учебный проект на React Native + Expo + TypeScript

Этот проект создан для систематизирования знаний по **React Native** с использованием **Expo CLI** и **TypeScript**.  
Цель — структурировать и систематизировать имеющиеся навыки разработки мобильных приложений, настройку проекта и структуру кода.

---

## 🚀 Технологии

- [React Native](https://reactnative.dev/) — фреймворк для создания мобильных приложений
- [Expo CLI](https://docs.expo.dev/) — инструменты для быстрого запуска и разработки
- [TypeScript](https://www.typescriptlang.org/) — типизация и улучшенный DX
- [React Navigation](https://reactnavigation.org/) (опционально) — навигация между экранами

---

## 📦 Установка и запуск

1. Установите [Node.js](https://nodejs.org/) (LTS-версию).
2. Установите Expo CLI (если ещё не установлен):
   ```bash
   npm install -g expo-cli
   ```
